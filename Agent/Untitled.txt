Task: Build a responsive, accessible, and high-performance  page/web application UI for a government/corporate platform  

Tech Stack & Architecture:
- Framework: Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.
- Icons: Lucide icons library only.
- Container: max-w-7xl mx-auto (1280px) with responsive padding (px-4 sm:px-6 lg:px-8).

Typography Rules:
- Font Family: Inter (sans-serif), optimized antialiasing (-webkit-font-smoothing: antialiased).
- Font Weights: Regular (400), Medium (500), Semibold (600), Bold (700), Extrabold (800).
 
- Letter Spacing: tracking-tight for headings (H1-H3), tracking-normal for body text.

Design System & Color Tokens (Light/Dark mode support):
- Primary (Brand Gold): #D19C30
- Deep Navy (Background/Surface Dark): #010c22
- Canvas Light: #EEEEEE
- Borders & Dividers: Clean corporate 

UI/UX & Smooth Transitions:
- Style: Clean Corporate, minimalist, highly professional, WCAG accessible.
- Smooth Transitions & Animations: Fast micro-interactions (duration-200/300), 
  smooth hover states, fading submenus, sliding mobile drawer, seamless 
  Light/Dark theme switching, and fluid page transitions.
- Loading States: Skeleton shimmer animation (custom gradient pulse for light/dark modes).
- Navigation: Desktop MenuItem & Submenu with hover dropdowns. Mobile responsive drawer.
- Language Switcher: Multilingual support (UZ, RU, EN via Next.js i18n). 
  Dropdown menu must display inline flag SVGs ONLY (no text labels for language names inside the toggle button).

Responsive Breakpoints: Maksimal Kenglik (Container)
- 'xs': '375px'
- 'sm': '640px'
- 'md': '768px'
- 'lg': '1024px' (Desktop menu and submenus activate here)
- 'xl': '1280px' (Main container max-w-7xl)
- '2xl': '1440px'


Output Requirements:
- Write modular, clean, type-safe Next.js components.
- Ensure strict mobile-first implementation and pixel-perfect responsiveness.
